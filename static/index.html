官方生态推荐 方式一：ol-mapbox-style 一键渲染全量 529 层主题样式
1. 在项目中引入 ol (v10+) 与 ol-mapbox-style (olms)。
2. 只需调用 olms.apply(map, styleUrl)，即可在 OpenLayers 画布上完美呈现与 MapLibre 完全一致的官方/高德/谷歌/暗黑/自定义矢量样式！

原生轻量 方式二：纯原生 OpenLayers (ol.layer.VectorTile + ol.format.MVT)
无任何外部样式库依赖，直接通过 OpenLayers 原生 style 函数对 74 个源层（如 AA 道路、BM 水系、BV 陆地）进行个性化着色与交互控制。 
import VectorTileLayer from 'ol/layer/VectorTile.js';
import VectorTileSource from 'ol/source/VectorTile.js';
import MVT from 'ol/format/MVT.js';
import { Stroke, Style } from 'ol/style.js';

const vtLayer = new VectorTileLayer({
  declutter: true,
  source: new VectorTileSource({
    format: new MVT(),
    url: 'http://127.0.0.1:8890/mvt/{z}/{x}/{y}'
  }),
  style: function(feature) {
    const sl = feature.get('layer'); // 获取天地图源层标识: AA, BM, BV, CE...
    if (sl === 'AA') return new Style({ stroke: new Stroke({ color: '#f59e0b', width: 2 }) });
  }
});

推荐方法 方式一：TileJSON 规范直接连接（最简、最稳、绝不报错）
1. 在 QGIS 左侧【浏览器】面板中右键【Vector Tiles】->【新建通用连接 (New Generic Connection)】。
2. 仅在 URL 处填入 TileJSON 地址，Style URL 留空，名称随意，点击确定即可！
避坑提示 方式二：XYZ 切片 + 样式（注意：切勿反填两项输入框！）
⚠️ QGIS 输入框排布陷阱：QGIS 对话框上排是「样式 URL (Style URL)」，下排是「URL（切片数据）」。
若颠倒填写，QGIS 会因切片源不含 {x}/{y}/{z} 而弹出 Layer is not valid / Repair Data Source！
（注：本服务已内置智能容错层，即使不小心颠倒填写亦能自愈兼容）
原生 REST 协议 从路径添加数据 (Add Data From Path)
1. 打开 ArcGIS Pro，进入顶部工具栏【地图 (Map)】。
2. 点击【添加数据 (Add Data)】下拉箭头 -> 选择【从路径添加数据 (Data From Path)】。
3. 将下方的 VectorTileServer 地址粘贴至输入框，点击【添加 (Add)】即可秒级渲染！
💡 ArcGIS Pro 兼容性说明：
• 完整 LODs 阵列：内置 0-18 级 Web Mercator 空间分辨率与比例尺，精准缩放。
• 未压缩 Protobuf 传输：tileCompression: "none" 彻底解决 Esri Gzip 解码冲突。
• 原生符号与样式：自动挂载 resources/styles/root.json 与 resources/sprites 精灵图。
